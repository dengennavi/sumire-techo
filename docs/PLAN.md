## 何を作ったか
宝塚ファン向け非公式PWA「すみれ手帖」
- **タカラット試算**（看板）：公式ルールで概算、上限込みで「次のステージまであと何円」を逆算、集計日と加算タイミングの締切を表示
- **初観劇ガイド＋当日モード**：流れ・マナー・用語、持ち物チェック
- **観劇手帖**：端末内だけの記録、JSONバックアップ
- **創立メンバー**（＝KPIの「会員」）：**LINE公式アカウントの有効友だち数（ブロック除く）**で数える（2026-11-04 ユーザー合意）。特典＝集計日7日前のお知らせ＋シェア用の創立メンバー証。ツール自体は登録不要

## なぜ勝てるか
- 公式アプリは「現在値」は見せるが「**あと何円・いつまでに**」は計算してくれない
- 制度が2025年4月開始でまだ複雑。上限・合算・加算タイミングを知らない人が多い
- **今が一番需要が高い**：12/31が集計日。オンライン購入は発送の約1か月後加算なので「**11/30までの発送分**」が締切。この話題で11月中に一気に告知する

## 拡散ネタ（事実ベース・公式で確認済み 2026-11-04）
1. 「友の会フル＋共通ID＋12か月＋チケット上限＋グッズ上限、全部やっても **2,484pt。ゴールド(2,500)に16pt足りない**」
2. 「ステージで当選確率は変わらない（公式明記）。変わるのは**申し込める抽選回**。ゴールドは第1抽選から」
3. 「キャトルレーヴオンラインは**発送の1か月後**に加算。12月集計に入れたいなら11月中の発送が目安」
4. 「キャトルレーヴは店舗とオンライン**合算で**上限1,000」
5. 「3月末にリセット。でも**友の会入会の300はリセットされない**」

## やらないこと（炎上・権利対策）
- 公式ロゴ・写真・ポスター・歌詞・出演者情報を使わない
- ランキング・掲示板・評価・口コミは作らない
- 「当選しやすくなる」とは絶対に言わない
- 転売・お茶会・チケット譲渡に関わらない
- 公式サイトへの自動ログイン・スクレイピングをしない

## 運用ルール
- 事実確認：Xのうわさは使う前に公式ページで確認（例：My Galleryの上限は1,000＝10万円。「タカラット2倍」キャンペーンは未確認なので発信しない）
- 制度改定チェック：月1回＋集計日前に公式ページを確認 → `rules.js` の `checkedAt` を更新 → `npm test`
- 終了時：LINEで告知 → LINE公式アカウント削除 → サイト削除
